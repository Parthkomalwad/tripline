# Security policy

## Report a vulnerability

Do not open a public issue for a security problem.

Report it privately through GitHub: open the **Security** tab of this repository and select **Report a vulnerability**.

Include:

- the affected version or commit,
- the steps to reproduce the problem,
- the impact that you expect.

## Response targets

| Step | Target |
|---|---|
| Acknowledge the report | 3 working days |
| Give a first assessment | 7 working days |
| Release a fix for a critical issue | 30 days |

We will tell you when we publish the fix. We will credit you unless you ask us not to.

## Supported versions

tripline has no release yet. After v0.1, only the latest minor release gets security fixes.

## Scope

The threat model in `docs/threat-model.md` lists what tripline protects against and what it does not.
